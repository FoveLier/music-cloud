# 云端音乐 · DESIGN

**Status: approved**

## 1. 概念

**夜航云村（Night Voyage）**：把听歌做成一次夜间航行。

- 底色是接近黑的墨蓝，像关灯后的房间。
- 主色是云红，不铺满，只给“播放/当前/重要动作”。
- 金色只给统计与唱片高光，像仪表盘上的灯。
- 封面是唯一的大色块；界面其余部分让位给封面和排版。
- 参考网易云音乐的“暗色 + 红 + 唱片”气质，但不复制 Logo、版权插画或原版布局。

## 2. 设计原则

1. **封面优先**：有数据的地方让真实封面说话，不用装饰图形抢戏。
2. **一屏一件事**：首页是“挑歌单”，歌单页是“挑歌”，播放页是“听”，统计页是“看结果”。
3. **让布局解释层级**：避免“标题 + 副标题 + 说明 + 标签”的 AI 式堆叠；同一信息只出现一次。
4. **动作要有回声**：按下、播放、切歌、加载、失败都有明确反馈，但不弹无意义弹窗。
5. **数据要诚实**：空就是空，旧就是旧，失败就是失败；不用假数据填满图表。

| `--red` | `#FF4D5A` | 主行动/播放/当前 |
| `--red-light` | `#FF8E96` | 红色浅字/选中标签 |
| `--red-deep` | `#C83242` | 红色按压/渐变暗部 |

规则：一屏红色面积不超过 15%；金色只做点缀；不使用紫色渐变。

### 3.2 Type

| 角色 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Display | 64rpx | 700 | 1.1 | 首页主标题 |
| H1 | 48rpx | 700 | 1.2 | 页面标题 |
| H2 | 36rpx | 600 | 1.3 | 区块标题/歌单名 |
| Body | 28rpx | 400 | 1.6 | 正文/歌词 |
| Body-strong | 28rpx | 600 | 1.5 | 歌名/数值 |
| Caption | 24rpx | 400 | 1.5 | 歌手/描述 |
| Micro | 20rpx | 500 | 1.4 | 序号/时长/eyebrow |

字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。数字使用 `font-variant-numeric: tabular-nums`。英文 eyebrow 用 4rpx 字距。

### 3.3 Spacing

以 `4rpx` 为光学微调栅格，主布局档位 `8 / 16 / 24 / 32 / 48 / 64rpx`，允许 `12 / 18 / 20 / 28 / 40rpx` 作为字距/图标/图表标签的微调。页面左右 gutter `32rpx`；卡片内边距 `28rpx`；区块间距 `40rpx`；列表行高 `112rpx`。

页面级满屏状态可使用 `100vh / 70vh` 表达视口高度；除此之外的组件尺寸、间距、圆角一律使用 rpx。此例外只服务跨端安全区，不用于普通组件布局。

### 3.4 Radius / Shadow / Motion

| Token | 值 |
| --- | --- |
| `--radius-sm` | `16rpx` |
| `--radius-card` | `32rpx` |
| `--radius-pill` | `999rpx` |
| `--shadow-card` | `0 24rpx 80rpx rgba(0,0,0,.35)` |
| `--ease` | `cubic-bezier(.2,.8,.2,1)` |
| `--press` | `180ms` |
| `--enter` | `260ms` |
| `--vinyl` | `18s linear infinite` |

动效只用于：按压反馈、页面进入、唱片旋转、歌词高亮、图表生长。没有循环呼吸/闪烁装饰。

## 4. 页面布局

### 4.1 首页 · 发现

```text
┌─────────────────────────────┐
│ 状态栏                      │
│ CLOUD MUSIC · 08            │
│ 今晚，听点什么              │
│ 把耳机戴上，让城市退后。    │
│                             │
│ ┌─────────────────────────┐ │
│ │ 热歌榜        [播放]    │ │  ← 主推歌单，封面大图
│ │ 200 首 · 此刻最热        │ │
│ └─────────────────────────┘ │
│                             │
│ 为你推荐            全部 →  │
│ [封面] 新歌榜       100 首  │
│ [封面] 飙升榜       100 首  │
│                             │
│ 页脚：数据来自本地 Meting    │
│ [发现]            [听歌报告] │
└─────────────────────────────┘
```

- 顶部不使用原生导航；`CLOUD MUSIC · 08` 是唯一英文 eyebrow。
- 主推卡：封面左侧/背景，右侧名称 + 数量 + 播放圆钮；封面用真实图。
- 列表行：96rpx 封面、名称、描述、右侧箭头；行间用 1rpx 分割，不用卡片套卡片。
- 底部 tabBar 原生；内容底部留 160rpx 安全区。

### 4.2 歌单页

```text
┌─────────────────────────────┐
│ ←  歌单                     │
│ ┌──────┐  热歌榜            │
│ │ 封面 │  200 首 · 华语/流行 │
│ └──────┘  [播放全部]        │
│ 简介：此刻最热的歌…          │
│                             │
│ 01  Hong Kong     The Weeknd  03:36  ▶
│ 02  海屿你         马也_Crabbit 04:55  ▶
│ 03  罗生门（Follow） 梨冻紧     03:24  ▶
│ ...                         │
└─────────────────────────────┘
```

- 页头使用封面作为背景，叠加墨色渐变，保证文字对比。
- 封面 232rpx 圆角 24rpx；名称 H1；数量/描述 Caption。
- 曲目行：序号 20rpx muted；歌名 Body-strong；歌手 Caption；时长 Micro；右侧 64rpx 播放按钮。
- 当前播放行（从播放页返回时）用红色左边条 + 红色序号；本次最小实现可只保留状态高亮。

### 4.3 播放页

```text
┌─────────────────────────────┐
│ ←  正在播放          [歌词] │
│                             │
│        ╭─────────╮          │
│       │  唱片封面 │          │  ← 旋转的黑胶
│        ╰─────────╯          │
│                             │
│  Hong Kong                  │
│  The Weeknd                 │
│                             │
│  01:12  ─────●──────  03:36 │
│                             │
│     ⏮      ⏸/▶      ⏭      │
│                             │
│  [唱片模式]    [歌词模式]    │
└─────────────────────────────┘
```

- 唱片：圆形封面 + 外圈黑胶纹理 + 中心红点；播放时 `rotate`，暂停时 `animation-play-state: paused`。
- 歌词模式：封面缩小/淡出，歌词区占主视觉；当前行 36rpx 白色，其余 28rpx muted，自动滚动。
- 控制：上一首/播放/下一首 88rpx 触控；播放按钮 128rpx 红色圆形；进度条 4rpx。
- 顶部有模式切换 pill；不使用“正在播放”重复次级标题。

## 5. 组件

| 组件 | 规格 |
| --- | --- |
| PageShell | 墨色底、左右 32rpx、状态栏安全区、底部 tabBar 安全区 |
| Eyebrow | 20rpx / 4rpx 字距 / 红或 muted |
| Cover | 圆角 24rpx；图片 `mode="aspectFill"`；失败用渐变 + 首字 |
| PlaylistHero | 封面 + 名称 + 数量 + 播放圆钮；红色面积克制 |
| ListRow | 112rpx 高；1rpx 分割；右侧箭头/播放 |
| TrackRow | 序号/歌名/歌手/时长/播放；当前行红色左边条 |
| Vinyl | 黑胶纹理 + 封面 + 中心点；18s 旋转 |
| PlayButton | 128rpx 红圆；白色三角；`hover-class` 缩放 0.94 |
| ControlButton | 88rpx 触控；线框图标/文字 |
| LyricLine | 28rpx muted；当前 36rpx 白 + 红色小点 |
| ChartCard | surface 底、32rpx 圆角、标题 + 420rpx 画布 |
| StateCard | 错误/空状态；标题 + 一句可执行提示 + 重试按钮 |

## 6. 文案

- 短、具体、有温度；例如“今晚，听点什么”“把耳机戴上，让城市退后”。
- 不写“这是一个……”“本页面用于……”这类说明书式次级标签。
- 错误文案必须可执行：“Meting 服务未启动？先在 meting-server 运行 npm start，再重试。”
- 空状态文案：“还没有播放记录。去发现一首歌，报告会自己长出来。”

## 7. 实现映射

- `app/uni.scss` 保存 SCSS token；页面内用 CSS 变量/常量复制同名值，保证 H5 与小程序一致。
- 封面、唱片、图表、按钮的尺寸全部 rpx；图表容器在页面样式显式高度。
- 原生 tabBar 使用 `static/tabbar/` 四张 PNG；播放页/歌单页不是 tab 页。
- 设计稿：`docs/prototype/index.html`。
